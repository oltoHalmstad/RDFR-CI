# Generated Results

This directory is regenerated by `python experiments/run_all.py`.

- `tables/` — CSV and Markdown manuscript/supplement tables.
- `figures/` — PNG and PDF figures.
- `scenario_results/` — one machine-readable JSON audit per scenario plus summary.
- `sensitivity/` — uncertainty, aggregation, weight, inter-rater and detector-threshold results.
- `logs/` — independent-witness style synthetic event logs.
- `reproducibility_manifest.json` — environment, configuration and SHA-256 output inventory.

`results/swat/` is ignored by Git because SWaT-derived results should only be generated by researchers with an authorized official dataset copy and should be reviewed against the provider's terms before release.
