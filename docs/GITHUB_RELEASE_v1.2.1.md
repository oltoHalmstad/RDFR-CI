# GitHub Release v1.2.1

**Tag:** `v1.2.1`  
**Release title:** **RDFR-CI v1.2.1 — Reproducibility-Aligned Supplementary and Reproducibility Package**

## Release description

RDFR-CI v1.2.1 is the reproducibility-aligned corrective release supporting the manuscript **“RDFR-CI: Risk-Driven Deployment and Forensic Readiness for Governing AI Authority in Critical Infrastructure Protection.”**

This release retains the computational and SWaT A11 results from v1.1.0 and aligns the repository metadata/documentation with the final MDPI submission master updated 8 September 2026.

### Included

- RDFR-CI reference implementation and configurable governance model;
- 30 illustrative scenarios spanning 18 critical-infrastructure sectors;
- six manuscript showcases;
- uncertainty, authority-ceiling, aggregation, weight, and inter-rater analyses;
- agentic/multi-agent non-transitive authority demonstrations;
- reproducible manuscript and supplementary figures/tables;
- pre-specified SWaT A1/A2 external-validation pipeline;
- executed SWaT A11 normal-operation threshold-transfer experiment;
- clearly separated controlled synthetic perturbation challenge for event-level `D(phi)`, authority mapping, and 10,000-resample bootstrap uncertainty;
- manuscript-to-repository mapping, claims ledger, reproducibility manifest, and figure/table reference audit.

### Scientific-status note

The supplied February 2026 SWaT A11 files contain no attack-label field. The next-day normal threshold-transfer results are empirical; the perturbation challenge is synthetic and is **not** reported as real SWaT attack-detection performance. Labeled A1/A2 attack validation remains pre-specified and is not claimed in this release.

### Data restriction

SWaT raw data are not redistributed. Researchers must obtain authorized data directly from the official provider and keep those files outside Git tracking.
