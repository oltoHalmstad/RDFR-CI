# Paper Support Files

This directory connects the RDFR-CI manuscript to the supplementary repository. It does not include the journal manuscript itself.

- `manuscript_reference.md` identifies the manuscript version supported by this release.
- `manuscript_to_repository_mapping.md` maps manuscript sections to implementation and outputs.
- `claims_ledger.csv` classifies major claims as reproduced, illustrative, pre-specified, externally data-dependent, or future work.
